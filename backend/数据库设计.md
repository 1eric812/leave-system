# 请假管理系统 - 数据库设计

## 数据表概览

| 表名 | 说明 |
|------|------|
| `sys_user` | 员工/用户表 |
| `leave_request` | 请假申请表 |
| `approval_record` | 审批记录表 |

---

## 1. sys_user（员工表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PRIMARY KEY | 员工ID（如 emp001, mgr001） |
| name | VARCHAR(50) | NOT NULL | 姓名 |
| dept | VARCHAR(50) | NOT NULL | 所属部门 |
| role | VARCHAR(20) | NOT NULL | 角色：employee-员工、manager1-部门经理、manager2-总经理 |
| level | INT | NOT NULL | 级别：1-员工、2-部门经理、3-总经理 |
| password | VARCHAR(100) | NOT NULL | 登录密码 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 更新时间 |

---

## 2. leave_request（请假申请表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PRIMARY KEY | 申请编号（如 REQ001） |
| user_id | VARCHAR(32) | NOT NULL, FK → sys_user.id | 申请人ID |
| user_name | VARCHAR(50) | NOT NULL | 申请人姓名 |
| dept | VARCHAR(50) | NOT NULL | 申请人部门 |
| leave_type | VARCHAR(20) | NOT NULL | 假期类型：年假/病假/婚假/丧假/其他 |
| start_date | DATE | NOT NULL | 开始日期 |
| end_date | DATE | NOT NULL | 结束日期 |
| duration | INT | NOT NULL | 请假天数 |
| reason | TEXT | NOT NULL | 请假原因 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'pending' | 状态：pending-待审批、approved-已批准、rejected-已驳回 |
| approval_level | INT | NOT NULL, DEFAULT 1 | 审批级别：1-一级审批、2-二级审批 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 更新时间 |

### 审批级别规则

**按用户角色分层：**

| 申请人级别 | 请假天数 | 审批流程 |
|-----------|---------|---------|
| 员工 (level 1) | ≤ 3 天 | 一级审批（部门经理审批即可） |
| 员工 (level 1) | > 3 天 | 二级审批（部门经理初审 → 总经理终审） |
| 部门经理 (level 2) | 任意天数 | 一级审批（总经理审批） |
| 总经理 (level 3) | 任意天数 | 自动批准 |

---

## 3. approval_record（审批记录表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PRIMARY KEY | 审批编号（如 APR001） |
| request_id | VARCHAR(32) | NOT NULL, FK → leave_request.id | 关联请假申请ID |
| approver_id | VARCHAR(32) | NOT NULL, FK → sys_user.id | 审批人ID |
| approver_name | VARCHAR(50) | NOT NULL | 审批人姓名 |
| action | VARCHAR(20) | NOT NULL | 操作：approve-批准、reject-驳回 |
| reason | VARCHAR(500) | DEFAULT '' | 审批意见 |
| approval_level | INT | NOT NULL | 审批级别：1-一级、2-二级 |
| timestamp | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 审批时间 |

---
